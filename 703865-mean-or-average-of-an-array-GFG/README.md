# [Mean or Average of an Array](https://www.geeksforgeeks.org/problems/mean0021/1)
## Easy
Given an array arr[], return the floor value of the mean of its elements.
Examples:

Input: arr[] = [1, 3, 4, 2, 6, 5, 8, 7]Output: 4Explanation: Sum of the elements is 1 + 3 + 4 + 2 + 6 + 5 + 8 + 7 = 36, Mean = 36/8 = 4.5, floor(4.5) = 4.

Input: arr[] = [4, 4, 4, 4, 4]Output: 4Explanation: Sum of the elements is 4 + 4 + 4 + 4 + 4 = 20, Mean = 20/5 = 4
Constraints:1 ≤ arr.size() ≤ 1061 ≤ arr[i] ≤ 106

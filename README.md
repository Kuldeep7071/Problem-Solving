*   C++

## 🧩 Platforms Covered

The problem directories are organized by the platform they originate from:

*   **LeetCode:** Folders formatted with problem numbers and titles (e.g., `0001-two-sum`, `0206-reverse-linked-list`).
*   **GeeksforGeeks (GFG):** Folders appended with the `-GFG` tag (e.g., `700889-reverse-an-array-GFG`).
*   **HackerRank:** Folders appended with the `-Hackerrank` tag (e.g., `8038-say-hello-world-with-c-Hackerrank`).

## 📂 Repository Structure

Each folder corresponds to a specific problem and generally contains:
1.  The source code of the accepted solution.
2.  A localized `README.md` detailing the problem statement (auto-generated by LeetHub for supported platforms).
